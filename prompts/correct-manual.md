## 답을 돌려주는 방법

아래 형식의 **JSON 하나만** 출력해라. 설명이나 인사말을 앞뒤에 붙이지 말고,
코드 블록으로 감싸도 된다. 한국어로 쓴다.

```json
{
  "scores": {
    "items": [
      { "id": "채점 기준 항목의 id", "awarded": 24, "reason": "왜 그 점수인지 한두 문장" }
    ],
    "deductions": [
      { "name": "감점 사유", "points": 5, "reason": "왜 깎았는지" }
    ]
  },
  "inlineComments": [
    {
      "quote": "답안에서 그대로 옮긴 짧은 대목",
      "severity": "good | info | warning | error",
      "category": "논지 파악 | 제시문 활용 | 구성 | 문장 | 분량 | 원고지",
      "message": "무엇이 문제인지",
      "suggestion": "어떻게 고칠지. 없으면 null"
    }
  ],
  "overall": {
    "summary": "이 답안이 어떤 답안인지 3~4문장",
    "strengths": ["잘한 점 2~4개"],
    "improvements": ["고칠 점 2~4개"],
    "nextSteps": ["다음에 바로 할 것 2~3개"]
  },
  "revisedExample": "학생 답안을 고쳐 쓴 글 전문"
}
```

### 반드시 지킬 것

- `items` 의 `id` 는 위 채점 기준에 적힌 id 를 **그대로** 쓴다. 다음 중에서만 고른다:
  {{ids}}
  항목을 빠뜨리지 말고 전부 채운다. `awarded` 는 그 항목 배점을 넘을 수 없다.
- `quote` 는 **답안 원문에서 글자 그대로** 옮긴 조각이어야 한다.
  한 글자라도 다르면 프로그램이 그 자리를 못 찾는다. 10~40자 정도가 알맞다.
  줄임표나 따옴표를 덧붙이지 말고, 있는 그대로 복사한다.
- 코멘트는 8~15개, 답안 전체에 고르게 단다. `good` 은 최소 2개 찾는다.
- 감점할 것이 없으면 `deductions` 는 빈 배열로 둔다.
